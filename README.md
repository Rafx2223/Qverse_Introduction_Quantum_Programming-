# QVerse Quantum Computing Course

Welcome to the official repository for the **QVerse Introduction to Quantum Computing and Quantum Programming Course**.

This repository contains all the material used throughout the course, including theoretical explanations, Jupyter notebooks, programming exercises, challenges, and additional resources.

The course is designed for students with **basic Python knowledge** who want to start learning quantum computing from scratch. No previous experience in quantum programming is required.

## About the Course

The objective of this course is to introduce the fundamental concepts behind **quantum computing** while progressively developing practical programming skills.

The course combines:

- Quantum computing fundamentals
- Basic quantum mechanics concepts applied to computation
- Quantum circuits and quantum gates
- Qubit measurement and superposition
- Entanglement
- Quantum algorithms
- Quantum programming with Python
- Qiskit and other quantum computing libraries
- Noise and real quantum hardware
- Variational quantum algorithms
- Quantum error correction
- Practical exercises and small projects

The content is inspired by educational resources such as **IBM Quantum Learning** and **Quantum Rings Quantum 101**, while being adapted to the learning objectives and activities of QVerse.


## Requirements

To follow the course, participants should have:

- Basic Python knowledge
- Basic linear algebra
- Basic understanding of complex numbers
- Curiosity about quantum technologies

Previous knowledge of quantum computing is **not required**.

Depending on the module, additional Python packages such as Qiskit may need to be installed. Instructions will be provided in the corresponding notebooks.

## How to Use This Repository

We recommend following the course in order.

1. Open the folder corresponding to the current week.
2. Read the introductory material.
3. Complete the associated Jupyter Notebook.
4. Try the exercises before checking any available solutions.
5. Experiment with the circuits and modify the provided code.

Quantum computing is best learned by combining theory with experimentation, so participants are encouraged to modify the notebooks and explore beyond the proposed exercises.
